# 💄 Cosmetic Insights: Navigating Cosmetics Trends and Consumer Insights with Tableau

## 📌 Project Overview

This project was developed as part of the **SmartBridge Internship**. The objective of this project is to analyze cosmetic product data using **Tableau Public** and transform raw data into meaningful business insights through interactive visualizations, dashboards, and stories.

The project helps users understand product categories, brand performance, pricing trends, customer ratings, and skin type compatibility.

---

## 🎯 Objectives

- Analyze cosmetic product data using Tableau.
- Create interactive visualizations for better data understanding.
- Design an interactive dashboard.
- Develop a Tableau Story to present insights.
- Identify trends in product categories, pricing, brands, and customer ratings.

---

---

## 🔍 Key Insights

- Moisturizers and cleansers represent a significant portion of cosmetic products.
- Premium brands generally maintain higher average prices.
- Higher product prices do not always result in better customer ratings.
- Combination and Normal skin products dominate the dataset.
- A small number of brands contribute a large share of the available products.
